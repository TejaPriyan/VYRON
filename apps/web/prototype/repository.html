Live GitHub Repository Analyzer

Enter any public GitHub repository (owner/name or a GitHub URL) to inspect live metadata from the GitHub REST API. VYRON shows exactly what GitHub answered, how fresh the cached reading is, and the exact API source URLs behind every figure.

What VYRON Reads Live from GitHub

  • Core counts & metadata: stars, forks, open issues and pull requests, default branch, archive/fork status, and SPDX license.
  • Language breakdown: exact byte shares reported by GitHub with zero opaque scoring.
  • Opt-in activity: top contributors, latest published release, and 52-week weekly commit counts requested only when you ask.
  • Portable evidence: download the full provenance-labelled JSON reading or jump straight into Side-by-Side Compare.

Example Public Repositories

Try pallets/flask, vercel/next.js, or rust-lang/rust. Programmatic JSON endpoint: GET /api/v1/github/repositories/{owner}/{repo}.

Figures are read from the GitHub REST API when you ask. Nothing is stored.
