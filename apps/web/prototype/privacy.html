Privacy & Data Handling

VYRON is designed to inspect public technology ecosystems without collecting personal profiles, setting tracking cookies, or storing data in your browser.

Zero Browser Storage & Zero Trackers

VYRON does not use localStorage, sessionStorage, cookies, advertising pixels, or third-party analytics scripts. Every interactive page enforces a strict Content Security Policy (default-src 'self', script-src 'self', connect-src 'self', frame-ancestors 'none') so your browser never makes direct third-party requests while using the application. Page state (such as a selected entity, repository, package, or comparison pair) lives only in the page URL query parameters.

Server-Side Upstream API Reads

When you inspect a public GitHub repository or a PyPI/npm package, the VYRON backend queries the public GitHub REST API, PyPI JSON API, or npm registry API on your behalf. Responses are kept briefly in ephemeral per-instance memory caches (around 10 minutes for package metadata, plus ETag validation for GitHub) to respect upstream rate limits. Nothing is persisted to a database, and no user account or personal token is collected.

Hosting Logs & Rate Limiting

To prevent abuse of shared upstream quotas, VYRON applies ephemeral in-memory per-IP fixed-window rate limiting. Application request logs omit query strings and personal tokens. Hosting infrastructure (Vercel) processes standard HTTP request metadata required to deliver responses and diagnose server errors. For privacy questions, see Contact VYRON.
