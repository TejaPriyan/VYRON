PyPI & npm Package Dependency Graph & Release History

Inspect declared dependencies for any Python (PyPI) or JavaScript (npm) package live on demand. VYRON reads one package at a time directly from the upstream registry and expands the layered dependency graph only when you open a node.

Transparent Dependency Classification

  • Draws unconditional runtime dependencies declared by each package's official registry metadata.
  • Explicitly counts and separates left-out conditional, dev, peer, and optional declarations rather than silently hiding them.
  • Includes an opt-in release history timeline and table recording exact registry dates (first_file_upload on PyPI, publish_time on npm).
  • Exports full JSON evidence packs with upstream registry URLs and cross-links to GitHub repositories.

Example Packages

Try Flask on PyPI or Express on npm. API endpoints: GET /api/v1/registries/{registry}/package?name=<pkg> and GET /api/v1/registries/{registry}/releases?name=<pkg>.

Each package is read from PyPI or npm when you open it. VYRON keeps an answer for about ten minutes and nothing is stored in your browser.
