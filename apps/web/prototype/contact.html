Contact VYRON

VYRON is an open-source project maintained on GitHub. Use the channels below to report bugs, propose new data readers or features, ask technical questions, or disclose security issues responsibly.

Bug Reports & Feature Requests

For bugs, API questions, provenance corrections, or enhancement ideas, open an issue in the public GitHub repository: github.com/TejaPriyan/VYRON/issues. When reporting an API error, include the request_id displayed on the page along with the repository or package name you queried.

Direct Maintainer Email

For private inquiries, collaborations, or privacy requests, email the project maintainer at teja1616150@gmail.com.

Security Disclosures & Contributing

Please do not open public GitHub issues for suspected security vulnerabilities. Review the repository's SECURITY.md policy and email the maintainer privately. All contributors agree to follow the project's Code of Conduct and Contributing Guide.
