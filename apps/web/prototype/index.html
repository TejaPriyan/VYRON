    VYRON — The Living Map of Technology

    VYRON is an open-source, provenance-first technology atlas and software ecosystem explorer. Explore how programming languages, frameworks, AI models, cloud platforms, repositories, and packages connect and evolve — with explicit provenance labels and exact upstream source URLs on every figure.

    Interactive Technology Map & Historical Timeline

    The map displays 60 development-seed entities, 68 relationships, and 20 auto-detected clusters with fuzzy search, an accessible text outline, a live shortest-path finder (/api/v1/graph/path), a historical year slider with Play/Pause playback, and client-side JSON evidence export.

    Live Ecosystem Readers & Side-by-Side Comparison

    • Live GitHub Repository Analyzer — inspect stars, forks, license, byte-share languages, opt-in top contributors & latest release, and 52-week commit activity directly from the GitHub REST API.
    • PyPI & npm Package Dependency Graph & Release History — read declared unconditional dependencies one package at a time and view registry release date timelines.
    • Side-by-Side Compare — compare two PyPI/npm packages or two public GitHub repositories with deterministic Shared vs. Only-A vs. Only-B diffs.

    Provenance, Privacy & Machine-Readable Discovery
