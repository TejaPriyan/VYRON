About VYRON: The Living Map of Technology

VYRON is an open-source, provenance-first interactive technology atlas and ecosystem explorer. It connects programming languages, frameworks, AI models, platforms, repositories, and software packages in one interface where every fact carries an explicit source label instead of opaque rankings.

Provenance-First Architecture

Software directories often blend verified telemetry with unverified claims. VYRON labels every fact with its exact provenance (sourced, estimated, inferred, predicted, user_generated, ai_generated, or seed). Deterministic graph algorithms and live upstream readers work on their own; any future AI layer is strictly optional and citation-checked, never the source of truth.

What Runs Today vs. Early Development Status

VYRON is in early development and is not production ready. Today's deployment runs a standard-library Python HTTP API (vyron_api, 21 of 34 OpenAPI routes implemented) alongside a dependency-free four-page TypeScript browser interface:

  • Interactive Technology Map — 60 development-seed entities, 68 relationships, 20 auto-detected clusters, fuzzy search, shortest-path tracing, and historical year playback.
  • Live GitHub Repository Analyzer — Live GitHub REST API readings with stars, forks, license, language shares, cache freshness, opt-in contributors/latest release, and 52-week commit activity.
  • PyPI & npm Dependency Graph & Release History — On-demand layered dependency exploration and registry release date timelines with exact upstream URLs.
  • Side-by-Side Compare — Deterministic shared vs. unique dependency and language diffs between two packages or two public GitHub repositories.

Planned future milestones include a full Next.js frontend, WebGL graph rendering at scale, PostgreSQL, Neo4j, and Redis persistence adapters, background ingestion workers, authentication, and an optional Gemini AI research layer.
